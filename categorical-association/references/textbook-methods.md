# 教科書的方法與公式（Agresti 3e，第 1–2 章）

使用者追問「這是怎麼算的」「為什麼可以這樣用」時才讀。節號對應 Agresti, *An Introduction to Categorical Data Analysis*, 3rd ed. (2019)。

## 1. 變數與資料（§1.1）

- **名目**：類別沒有順序（血型、政黨）。**有序**：類別有自然順序（滿意度、教育程度）（§1.1.2）。
- 同一組類別可以依問題當名目或有序；**有序方法能用時通常比較有力**。
- 數字代碼（1–4）不代表一定是有序，要問使用者。
- 本章方法都假設觀察值彼此**獨立**（§1.1.3）。

## 2. 兩個比例的比較（§2.2–2.3）

2×2 表，列 i = 1, 2 是兩組，π_i 是第 i 組「成功」的機率，樣本比例 p_i = y_i / n_i。

| 效果量 | 定義 | 無關聯時 | 節 |
|---|---|---|---|
| 比例差 | π₁ − π₂ | 0 | §2.2.2 |
| 相對風險 | π₁ / π₂ | 1 | §2.2.3 |
| 勝算比 | θ = [π₁/(1−π₁)] / [π₂/(1−π₂)]，樣本 θ̂ = n₁₁n₂₂ / (n₁₂n₂₁) | 1 | §2.3.1 |

- 勝算比的 Wald 區間：log θ̂ ± z·SE，SE = √(1/n₁₁ + 1/n₁₂ + 1/n₂₁ + 1/n₂₂)（§2.3.3）。本 Skill 用 **score 區間**，小樣本表現較好，且有 0 格時仍可計算（§2.3.3）。
- 勝算比 ≈ 相對風險，**只在兩組比例都很小時**成立（§2.3.4）。
- case-control 研究的 Y 邊際是研究者決定的，π_i 無法估計，**只能報告勝算比**（§2.3.5）。
- 勝算比對換列換欄是對稱的：把 X、Y 角色交換不影響 θ（§2.3.1）。

## 3. 卡方獨立性檢定（§2.4）

H₀：X、Y 獨立，π_ij = π_i+ π_+j。期望次數 μ̂_ij = n_i+ n_+j / n。

- Pearson 統計量：X² = Σ (n_ij − μ̂_ij)² / μ̂_ij（§2.4.1）
- 概似比統計量：G² = 2 Σ n_ij log(n_ij / μ̂_ij)（§2.4.2）
- 大樣本下兩者都近似卡方分配，df = (I − 1)(J − 1)（§2.4.3）
- **標準化殘差**：(n_ij − μ̂_ij) / √[μ̂_ij (1 − p_i+)(1 − p_+j)]；|值| > 2 或 3 表示該格偏離獨立（§2.4.5）
- 近似條件：書中提醒期望次數太小時大樣本近似不可靠，改用精確檢定（§2.4.7）。本 Skill 用 Cochran 準則判斷：2×2 表有任何一格 < 5；更大的表有任何一格 < 1，或超過 20% 的格子 < 5（見 `checklist.md` 第 1 條）
- 卡方檢定**不管類別順序**：把列或欄重新排列，X²、G² 都不變（§2.4.7）。

## 4. 有序變數的趨勢檢定（§2.5）

給 X 的類別分數 u₁ ≤ u₂ ≤ …、Y 的分數 v₁ ≤ v₂ ≤ …，計算分數之間的樣本相關 r。

- **M² = (n − 1) r²**，H₀ 為獨立時近似卡方 df = 1（§2.5.1）
- 單尾檢定用 M = √(n − 1) · r，近似標準常態（§2.5.1）
- 二元變數的兩個分數怎麼選都不影響 M²。本 Skill 把兩種情況分開命名：Y 二元、X 有序 → **Cochran–Armitage 趨勢檢定**（§2.5.5）；X、Y 都有序 → **linear-by-linear association 檢定**（§2.5.1）。X 是二元名目、Y 有序時，第一版不做趨勢檢定（需要確認分析目的）
- r 的大小受邊際分配影響，不適合單獨當關聯強度（§2.5.2）
- **為什麼比卡方有力**：真有線性趨勢時，M² 把證據集中在 1 個自由度；X² 分散在 (I−1)(J−1) 個（§2.5.3）
- **分數的選擇**：等距分數最常見；類別間距不等時可用中點；不同的合理分數通常結論相近，但要做敏感度分析（§2.5.4）
- 名目變數（超過 2 類）沒有分數可給，不能用 M²（§2.5.5）

## 5. 小樣本：Fisher 精確檢定（§2.6）

- 固定兩個邊際，n₁₁ 在 H₀ 下服從**超幾何分配**（§2.6.1）
- P 值 = 比觀察值更極端的機率總和
- 因為分配是離散的，Fisher 檢定**偏保守**（實際型一錯誤小於 α）；**mid-P** = P(更極端) + ½P(等於觀察值)，較不保守（§2.6.3）。本 Skill 第一版為了避免同時給多種 P 值造成混淆，只報 Fisher 精確檢定的 P 值；mid-P 留作之後的延伸

## 6. 三因子表：控制第三個變數（§2.7、§4.3.4）

在 Z 的每一層 k 有一張 2×2 **部分表**（partial table）（§2.7.1）。

- **條件勝算比** θ_XY(k)：Z 固定在第 k 層時 X、Y 的勝算比（§2.7.4）
- **邊際勝算比**：把 Z 合併後、忽略 Z 的勝算比（§2.7.4）
- **Simpson 悖論**：條件關聯與邊際關聯方向相反；原因是 Z 同時和 X、Y 有關（§2.7.3）
- **條件獨立**：每一層 θ_XY(k) = 1。條件獨立**不代表**邊際獨立（§2.7.4）
- **同質關聯**：每一層勝算比相同 θ_XY(1) = … = θ_XY(K)（§2.7.5）
- **CMH 檢定**：H₀ 條件獨立；書中說明它就是上述模型 H₀: β = 0 的 score 檢定（§4.3.4）。常見公式 CMH = [Σ_k (n₁₁ₖ − μ₁₁ₖ)]² / Σ_k Var(n₁₁ₖ)，df = 1（書中未列公式）
- **Mantel–Haenszel 共同勝算比**：θ̂_MH = Σ_k (n₁₁ₖn₂₂ₖ / n₊₊ₖ) / Σ_k (n₁₂ₖn₂₁ₖ / n₊₊ₖ)（書中未列；本 Skill 主要報告模型的 exp(β)）
- 本 Skill 也用 logistic 模型 logit(π) = α + βx + β_k^Z：exp(β) 是共同勝算比（profile 區間），同質性檢定等於這個模型的適合度檢定（deviance），也就是加入交互作用的概似比檢定（§4.3.4、§5.2.1）
